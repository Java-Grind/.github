**Java Grind** — не учебный курс с единственным маршрутом. Здесь участники делают небольшие воспроизводимые эксперименты, делятся выводами и развивают работы друг друга.

## Начать

[Открыть каталог лабораторных →](LABS.md) · [Предложить идею →](https://github.com/Java-Grind/.github/issues/new) · [Создать Pull Request →](https://github.com/Java-Grind/.github/compare)

> [!TIP]
> Не знаете, с чего начать? Возьмите любую лабораторную со статусом `open` в [каталоге](LABS.md).

## Как это работает

1. Выберите лабораторную в [каталоге](LABS.md) и запустите её код.
2. Не нашли нужную тему — создайте [Issue](https://github.com/Java-Grind/.github/issues/new).
3. Сделайте свою лабораторную или улучшение и отправьте Pull Request.

## Что ценим

- **Работающий пример.** У каждой лабы есть цель, запуск и наблюдения.
- **Свободный маршрут.** Можно начать с любой темы и сделать ответвление.
- **Открытый вклад.** Идея, черновик, замер, ревью или документация — полезный вклад.
