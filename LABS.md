# Карта лабораторных Java Grind

Это роутинг-файл сообщества. Темы заданы примерно от простого к сложному; внутри каждого раздела участники добавляют свои реализации как ссылки на репозитории организации `Java-Grind`.

## Как читать и дополнять карту

- **Уровень** — ориентир по предполагаемой базе, а не обязательная последовательность.
- **Лабораторная** — конкретная работа участника. Одна тема может иметь много независимых реализаций.
- Для новой работы выберите подходящую строку темы, добавьте ссылку на репозиторий, теги и одно предложение о результате.
- Если темы нет, добавьте её в ближайший раздел и сохраните порядок от базовых концепций к более сложным.

| Статус | Значение |
| --- | --- |
| `open` | лабораторную можно проходить, обсуждать и улучшать |
| `draft` | работа ещё развивается |
| `idea` | нужна первая реализация или автор |

## Дерево тем

```text
01. Основы Java
    ├── синтаксис, типы, операторы
    ├── условия и циклы
    ├── методы, массивы и строки
    └── отладка и исключения
02. Объектная модель
    ├── классы, объекты, инкапсуляция
    ├── наследование, полиморфизм, интерфейсы
    └── records, enum, sealed classes
03. Работа с данными
    ├── Collections и Generics
    ├── equals/hashCode и Comparator
    ├── Lambda и Stream API
    └── Date/Time, Optional, I/O и NIO
04. Качество кода и инструменты
    ├── JUnit, моки и тест-дизайн
    ├── Maven или Gradle
    ├── логирование и конфигурация
    └── clean code и рефакторинг
05. Конкурентность
    ├── Thread, synchronized и locks
    ├── ExecutorService, Future и CompletableFuture
    ├── concurrent collections и coordination
    └── virtual threads и structured concurrency
06. JVM и производительность
    ├── память, GC и class loading
    ├── профилирование и диагностика
    ├── JMH и корректные бенчмарки
    └── performance tuning
07. Backend и экосистема
    ├── HTTP, JSON и базы данных
    ├── JDBC, JPA и транзакции
    ├── Spring Boot
    └── безопасность, observability и deployment
```

## Добавить свою лабораторную

1. Создайте репозиторий в организации `Java-Grind` с понятным именем, например `virtual-threads-http-lab`.
2. Добавьте в нём README: цель, требования, запуск, наблюдения и ограничения эксперимента.
3. Вставьте в таблицу строку рядом с нужной темой:

```md
| 05 | Virtual threads | [Моя лабораторная](https://github.com/Java-Grind/virtual-threads-http-lab) | `java`, `concurrency`, `virtual-threads` | `draft` | Что проверяет работа и какой получен результат. |
```

4. Откройте pull request в этот репозиторий.
