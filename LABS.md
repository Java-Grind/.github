## Через GitHub

1. Хотите пройти лабораторную? Откройте её название в каталоге — там код и инструкция запуска.
2. Не нашли нужную тему? [Создайте Issue](https://github.com/Java-Grind/.github/issues/new) с идеей.
3. Сделали лабораторную? Добавьте строку ниже и [откройте Pull Request](https://github.com/Java-Grind/.github/compare).

`open` — можно брать в работу · `draft` — в процессе · `idea` — нужна первая реализация · `looking-for-help` — нужен соавтор.

## Добавить лабораторную

1. Создайте репозиторий и опишите в README цель, запуск и наблюдения.
2. Добавьте строку в каталог и откройте Pull Request.

```md
| [LAB-002 · Короткое название](https://github.com/Java-Grind/your-lab) | Что исследует работа. `java` `тема` | `draft` |
```
