# Java Grind

> Открытое сообщество для совместного изучения Java через практические лабораторные.

Мы не идём по одному учебнику и не ждём «идеального» задания. Участники выбирают тему, делают небольшую лабораторную, публикуют её в репозитории организации, делятся наблюдениями и помогают друг другу с ревью.

## Чем занимаемся

- изучаем Java от основ языка до JVM, конкурентности и производительности;
- создаём и проходим лабораторные с работающим кодом, инструкцией запуска и выводами;
- обсуждаем решения, улучшаем эксперименты и добавляем следующие шаги;
- собираем открытый каталог работ, чтобы любой мог выбрать тему подходящей сложности.

## Как присоединиться

1. Откройте [LABS.md](LABS.md) и выберите тему или уровень.
2. Найдите существующую лабораторную либо предложите новую в подходящей строке карты.
3. Создайте репозиторий в организации `Java-Grind` и добавьте туда код, README с целью и инструкцией запуска.
4. Добавьте в `LABS.md` ссылку на репозиторий, теги и короткое описание результата.
5. Откройте pull request — так сообщество сможет посмотреть работу и помочь её развить.

## Принципы

- **Практика важнее коллекции ссылок.** У каждой лабы есть воспроизводимый пример.
- **Маршрут открыт.** Можно начать с любой подходящей темы и создавать ответвления.
- **Сложность растёт постепенно.** Карта идёт от основ к продвинутым темам, но не диктует единственный путь.
- **Вклад доступен всем.** Черновик, вопрос, замер или улучшение документации — полноценный вклад.
